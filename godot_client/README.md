# Godot thin-client spike

Minimal **Godot 4.3+** project that talks to the existing Snowcrash Python MMORPG server over WebSocket. It does **not** simulate the street.

Research + architecture: [`docs/godot-client.md`](../docs/godot-client.md) (issue **#109**).

The Godot **editor/binary is not required in this repo** and was not installed on the research box. These files are still a valid project — open them in a local Godot 4.x editor.

## Open in Godot Editor

1. Install [Godot 4.3 or newer](https://godotengine.org/download) (4.4.1+ if you later add GodotSteam).
2. Start the **dev** MMORPG server (shared world, port **8766**):

   ```bash
   cd /path/to/adventure-snowcrash   # or the adventure-dev worktree
   source .venv/bin/activate
   ./scripts/run_dev.sh              # → http://127.0.0.1:8766/  and  ws://127.0.0.1:8766/ws
   ```

3. Launch Godot → **Import** → select `godot_client/project.godot` (or Project → Import).
4. Press **F5** (Run Project). Main scene is `scenes/main.tscn`.
5. Leave the URL as `ws://127.0.0.1:8766/ws`, enter a courier name, **Jack in**.
6. Status should go `connecting…` → `ONLINE · <player id>`. The label shows HP / Focus / tile / objective and a cropped ASCII `state.map`.
7. Click the map (or anywhere that is not a LineEdit) then **WASD** to move, **Q/E** to turn (same relative actions as the web client).

Production server default is port **8765** — change the URL if you point at that process.

## Layout

| Path | Role |
|------|------|
| `project.godot` | Godot 4.3+ config, GL Compatibility renderer |
| `scenes/main.tscn` | Name gate, status, snapshot summary, ASCII map `Label` |
| `scripts/net_client.gd` | `WebSocketPeer` — join / action / chat / ping / reconnect |
| `scripts/main.gd` | UI wiring + hold-to-move |
| `icon.svg` | Placeholder Catppuccin Mocha icon |

`.godot/` is generated by the editor — gitignored.

## Protocol (short)

First text frame after connect **must** be:

```json
{"type":"join","name":"Courier"}
```

Server replies `welcome` (`you` + `state`) then `snapshot` frames. Intents: `{"type":"action","action":"forward","arg":null}`. Full notes in `docs/godot-client.md`.

## Out of scope (this spike)

FPV raycast, StreetNet dock, year panels, Steam/mobile export, Godot addons as mods. Those are designed in the research doc, not implemented here.
